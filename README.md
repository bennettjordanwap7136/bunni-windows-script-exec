## Bunni PC Overview

Bunni PC provides Windows users with a desktop environment for Lua injection and script management in Roblox. Its streamlined interface is built for quick navigation, simple script access, and a compact execution workflow.

Alongside its script executor, the project includes a hub containing more than 500 scripts. Persistent queue storage, batch execution, and an automatic update engine are also included. The lightweight UI is designed for Windows 10 and Windows 11 systems.
